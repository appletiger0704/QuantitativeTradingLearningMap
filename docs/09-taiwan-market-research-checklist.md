# 09 — 台灣市場量化研究檢核表

本章列出把玩具策略改為台股真實研究時，**必須先研究、實測與留下規格**的項目。交易制度、費率、資料服務與申報時程可能改變，任何真實使用前都應以適用的交易所、監管及券商最新公告核對。

## A. 資料與交易日

- [ ] TSE／OTC、上市／上櫃、股票／ETF 分類及來源。
- [ ] 交易日曆、國定休市、臨時休市、資料收盤後的實際發布時間。
- [ ] 股票代號保留字串型別（包含前導零）；避免把不同市場的代號混為一談。
- [ ] 歷史上市／下市、停牌／恢復交易、增減資、拆併股。
- [ ] 除權息與 ETF 配息的價格調整口徑；分清「訊號價、成交價、總報酬價」。
- [ ] 公告財報的當時可取得時間（`published_at`）；不可將事後修訂資料當成當日可得資訊。

## B. 執行與成本

- [ ] 每一種商品／交易方式適用的手續費、稅費與最低收費。
- [ ] 整股、盤中／盤後零股、申報時間與成交條件。
- [ ] 漲跌幅限制、最低升降單位、流動性、買賣價差及滑價。
- [ ] 若隔日開盤無成交量、跳空、漲跌停、停牌，策略如何延後或取消訊號。
- [ ] 部位上限、換手率、現金預留、風控與實際持倉對帳。

## C. 研究正確性

- [ ] 可重現股票池與交易時點（避免 Survivorship / Look-ahead）。
- [ ] 股價指數與 ETF 的總報酬基準是否一致。
- [ ] 對不同波動市場、不同市值層級與不同歷史區段測試。
- [ ] 成本後績效、Drawdown、換手、交易次數與風險調整比較。
- [ ] 每次資料修訂新增 audit revision，**不覆寫**早期研究結果。
- [ ] 排程失敗、資料過期與風控禁買能分別輸出 NO_DATA、BLOCKED。
