# 07 — Lab 1：建立第一個可執行的均線策略回測

本章對應 [P0、P3、P4](00-roadmap.md)。先用 **完全合成的行情** 理解資料 → 訊號 → 下一交易日成交 → 淨值；**不代表任何真實台股回測績效**。

## 1. 先跑起來

需求：Python **3.10+**；不需要安裝第三方套件。

在儲存庫根目錄執行：

```bash
python examples/lesson01_ma_backtest.py
python -m unittest discover -s examples -p "test_*.py" -v
```

Windows 可改用 `py`；macOS / Linux 如果 `python` 不存在，請用 `python3`。資料路徑在 `examples/data/toy_bars.csv`，測試在 `examples/test_lesson01_ma_backtest.py`。

## 2. 精確理解這個 Lab

簡化策略設定：

- 資料：14 筆**虛構日線**，只測算術與時間順序。
- 快均線：前 3 根（含當日）收盤平均；慢均線：前 5 根（含當日）收盤平均。
- 訊號：快均線大於慢均線 → 目標持有；否則 → 目標空手。前 4 天歷史資料不足，目標為 `None`。
- T 日收盤後才知道 T 日均線訊號；若需要交易，只能在 **T+1** 的開盤**假設**成交。
- 有效目標 ≠ 每天重複下單：已持有不重複買；已空手不重複賣。
- 此教材用整數「股」和簡化費用／滑價，**未實作台股整股、零股、撮合、稅費分類或漲跌停限制**。

## 3. 預期結果（不是獲利示範）

使用零成本測試可檢驗如下時間序列：

| 訊號產生日 | 訊號 | 實際模擬成交日 | 無成本成交價格 |
|---|---|---|---|
| 2026-01-12 收盤後 | 目標持有 → BUY | 2026-01-13 開盤 | 12 |
| 2026-01-19 收盤後 | 目標空手 → SELL | 2026-01-20 開盤 | 8 |

主程式預設另包含**任意教學假設**：單邊手續費率 0.1%、賣出額外稅率 0.3%、單邊滑價 0.1%。這些數字**不是目前台灣股票或 ETF 的正式費率**，不得直接帶入真實交易。

測試要驗證：
1. 訊號日嚴格早於成交日。
2. 單獨截去最後一天的資料，不影響先前訊號（前視偏誤測試）。
3. 最後一天收盤形成的訊號，**不能**假設同日成交。
4. 交易成本會降低最終淨值。
5. 重複交易日、無效參數與無效資金量被拒絕。

## 4. 修改程式實驗（建議順序）

- **Exercise A — 指標**：把 `fast=3, slow=5` 換成 `fast=2, slow=4`；比較訊號日與交易次數。寫下原本對參數影響的假設。
- **Exercise B — 前視偏誤**：故意把 `targets[i - 1]` 改成 `targets[i]`，觀察會產生什麼「不可能知道當日開盤時的收盤訊號」；完成後務必還原。
- **Exercise C — 費用**：設成零成本，再逐步提高費率與滑價，記錄淨值變化。
- **Exercise D — 資料驗證**：將 CSV 某列的 `high` 改成小於 `close`，檢查報錯而不是照樣回測。
- **Exercise E — 測試**：加入一個測試，確保無足夠歷史資料時沒有委託成交。

每個練習提交：實驗目的、修改的參數、執行指令、觀察結果、限制與結論（可以使用 [實驗紀錄模板](06-exercises-checklist.md)）。

## 5. 下一步：從玩具範例進入台股研究

- 先接入可追溯的官方／授權行情，並確認日期、時區、資料品質與存活者偏誤。
- 改為交易所交易日曆，而非假設每個工作日都開市。
- 加入證券別手續費、交易稅、最低費用、整／零股、最低跳動單位、可交易性、股票停牌與漲跌停限制。
- 處理股利／除權息、股票分割、ETF 配息與 Benchmark 口徑。
- 再做樣本外測試與紙上交易。**在完成這些工作前，不可使用此 Lab 當作真實下單依據。**

能親自解釋「為何 1/12 收盤的訊號不能在 1/12 開盤成交」，並自行撰寫前視偏誤測試與交易成本敏感度實驗。
