# 00 — 完整量化交易學習路線

## 最終成果（先訂驗收目標）
- 每個台股交易日收盤後取得可追溯的資料快照；產出下一個可執行時點的 **BUY / SELL / HOLD / NO_DATA / BLOCKED** 訊號。
- 訊號有策略版本、行情日期、產生時間、理由、風控結果、預估成本與可核對的輸入資料。
- 有包含交易成本的回測、樣本外／走期驗證、基準比較與紙上交易紀錄。
- **不自動下單**，資料不完整或檢核失敗時不出交易建議。

## 分階段學習（週數僅供安排，完成標準優先）
| 階段 | 必學內容 | 動手實作 | 完成條件 |
|---|---|---|---|
| P0 工具 | Python、venv/uv、Git、Pandas、NumPy、pytest、時間序列 | 讀 CSV、製作可重現環境 | 其他電腦依 README 可執行 |
| P1 市場 | 台股交易流程、OHLCV、報酬、複利、風險 | 資料檢查及績效計算 | 可解釋 CAGR、MDD、Sharpe |
| P2 資料 | API / CSV、公司行動、存活者偏誤、資料發布時間 | 統一資料格式、資料品質測試 | 錯誤、缺值、重複可檢出 |
| P3 指標 | MA、Momentum、RSI、波動度、量價 | 實作並單元測試指標 | 同輸入得同結果且無未來資料 |
| P4 回測 | 訊號與成交分離、現金與持倉、成本、基準 | 完成單策略日線回測 | 避免當日收盤訊號當日成交 |
| P5 策略 | 趨勢、動能、均值回歸、因子 | 至少兩類策略比較 | 研究假設與失效條件清楚 |
| P6 驗證 | OOS、walk-forward、敏感度、過度擬合 | 成本壓力、時間／標的穩健性 | 有明確淘汰門檻與報告 |
| P7 系統 | 配置、排程、訊號、風控、報表、告警 | 日更 MVP（不下單） | 重跑冪等、失敗安全、可追溯 |
| P8 模擬 | 紙上交易、人工覆核、作業監控 | 連續模擬並記錄偏差 | 實際執行偏差與事件均有紀錄 |
| P9 進階（選修） | 多因子、最佳化、ML、風險模型 | 獨立研究案 | 必須優於簡單基準且通過 OOS |

## 強制關卡
- P2 前不要相信任何回測。
- P4 前不最佳化策略參數。
- P6 前不宣稱策略有可交易的優勢。
- P8 前不以真實資金驗證系統正確性。
- 任何 Phase 都要保留反例與失敗實驗。

```text
假設 → 明確規則 → Point-in-time 資料 → 訊號 → 下一可成交時點
```
